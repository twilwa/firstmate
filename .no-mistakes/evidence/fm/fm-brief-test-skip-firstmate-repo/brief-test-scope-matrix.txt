=== brief fm-safe-suite ($LAB/data/fm-safe-suite/brief.md) ===
## Test scope
Scope: safe-suite.
Permits: the suite minus the committed exclusion manifest `tests/safe-suite-exclusions.txt`; never the full local suite. If the target repo has no such manifest, say so in your first status line and run focused tests instead.
Expected duration: about 249 minutes run serially in the Firstmate repo, from bin/fm-test-run.sh's measured duration hints; any other repo has no measured figure, so record your own estimate in your first status line before running anything.
Exclusion manifest: in the Firstmate repo, run `xargs bin/fm-test-run.sh --all < tests/safe-suite-exclusions.txt`.
When the no-mistakes Test step asks for approval, approve it and run the safe-suite selection named by this test scope; never skip it.
If the Test step times out, report needs-decision; never choose fix.


=== brief fm-full ($LAB/data/fm-full/brief.md) ===
## Test scope
Scope: full.

Any other repo has no measured figure either.
When the no-mistakes Test step asks for approval, approve it and run the full selection named by this test scope; never skip it.
If the Test step times out, report needs-decision; never choose fix.
